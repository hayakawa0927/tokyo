## 制服

1章・2章の学校（業平と、2章の墨田区の学校）は、どの学校も同じ制服にする。

- 男子: 黒の学ラン（詰襟・金ボタン）、中は白いシャツ、黒のズボン
- 女子: 紺のセーラー服（白い上着に紺の襟と袖口・赤いスカーフ）、紺のプリーツスカート、白いソックス
- 剣道着・柔道着・まわしなど部活の服を着るキャラは、キャラごとの「外見」のとおりにする
- 3章の勢力は、勢力ごとの装い（[chapter3-visuals.md](chapter3-visuals.md) の勢力の表）にする

## 背の高さ

固有キャラの背の高さ。天城 閃を175cmとして、ストーリー画面の頭の位置（web/src/Portrait.tsx の `WAIST_HEAD_TOP`）から割り出した。集合画像（[faction-group-prompts.md](faction-group-prompts.md)）など、複数のキャラを並べて描くときに使う。

- 割り出し方: ストーリー画面での頭のてっぺんの高さ（画面の下端から）の差を、そのまま背の高さの差とする。閃の画像は腰の下あたりまでなので、見えている頭から下端までを、閃の背の半分（87.5cm）として換算する
- 頭のてっぺんは画像から割り出した。頭より上に持ち物や手がある画像（浜崎・叢雲・早乙女・神宮寺・大鳥・一ツ橋・鮫島）は、頭の位置を目で見て直した
- この表が背の高さの正。見た目の資料（この文書と [chapter3-visuals.md](chapter3-visuals.md)）の体格の書き方は、この表に合わせる

## 天城 閃（あまぎ せん）

- 決まっていること: 男子・2年・主人公。名前の由来は「雷のような激しさ」。攻撃が最も高い（攻7・防6）。必殺技「雷穿（ライトニング・ピアサー）」で敵の指揮官を一点突破する。挑発されても表情を変えず「どけ」と言う。追い込まれると少しだけ笑う。制服の袖をまくって戦う。体育館の喧嘩で2年をまとめた
- 見た目の案: 黒髪の無造作な短髪、鋭い目つき。学ランを前開きにし、袖をまくっている。拳に巻いたテーピング。差し色は黄色（シャツの下のTシャツなど）

外見:
```
天城 閃（あまぎ せん）。男子高校2年生、主人公。雷のような激しさを内に秘めた、冷静な男。
黒髪のやや無造作な短髪、鋭く落ち着いた目。引き締まった体つき。
黒い学ランを前開きで着て、袖をまくっている。中は白いシャツ、その下に黄色のTシャツが少しのぞく。
拳にテーピング。
```

| 種類 | ポーズ・表情 |
|---|---|
| 腰より上 | 感情を表に出さない静かな表情。口元にわずかな笑み。片手をポケットに入れている |
| 全身 | 右を向き、片拳を前に突き出す一点突破の構え。重心を前に低く落とす |

## 風間 爽太（かざま そうた）

- 決まっていること: 男子・2年・主人公の相棒。名前の由来は「風のように自由」。速さが最も高い（速7）。必殺技「風鳴（かぜなり）」で敵の部隊を薙ぎ払う。軽口をたたき、閃に呆れながらも「付き合ってやるよ」と乗る。投げ技も使う
- 見た目の案: 明るめの茶髪で、少し長めの髪。人懐っこい笑顔。上着は肩にかけ、シャツの裾は出している。スニーカー。差し色は緑

外見:
```
風間 爽太（かざま そうた）。男子高校2年生、主人公の相棒。風のように自由な、軽口の多い男。
明るい茶髪で、軽くはねた少し長めの髪。細身で身軽な体つき。
学ランの上着を肩に引っかけ、白シャツの裾は出している。首に緑のヘッドホン（コードなし）。スニーカー。
```

| 種類 | ポーズ・表情 |
|---|---|
| 腰より上 | 余裕のある人懐っこい笑み。片手を頭の後ろに回し、呆れたような軽いしぐさ |
| 全身 | 右を向き、片足に重心を乗せて今にも駆け出しそうな軽い構え。上着が後ろになびく |

## 桐生 翼（きりゅう つばさ）

- 決まっていること: 男子・1年のリーダー。生意気な天才肌で、上級生をなめていて口が達者な負けず嫌い。混乱の中で誰よりも早く状況を読み、段取りを組んで1年をまとめた。閃に負けて閃を認め、口では逆らいながらついてくる。購買・食堂を押さえていた。必殺技「差し入れ」で味方の兵を回復する（「腹が減ってはなんとやら、ってね！」）
- 見た目の案: 中背で、閃たちより少し幼い顔。毛先のはねた髪。学ランの下にパーカー。購買のパンの袋。挑発的なニヤリ顔

外見:
```
桐生 翼（きりゅう つばさ）。男子高校1年生、1年生をまとめたリーダー。生意気な天才肌の後輩。
中背でやや細身、先輩たちより少し幼さの残る顔。毛先のはねた髪。頭の回転が速そうな目。
学ランの下にグレーのパーカーを着込み、フードを外に出している。
```

| 種類 | ポーズ・表情 |
|---|---|
| 腰より上 | 上級生をなめた、自信満々のニヤリ顔。人差し指を立てて何か言い返している |
| 全身 | 右を向き、片手に購買のパンの袋を掲げ、もう片方の手で手招きして挑発している |

## 氷室 怜（ひむろ れい）

- 決まっていること: 男子・3年・生徒会長。1章のボスで、倒すと仲間になり参謀になる。知力が最も高い（知6）。必殺技「凍てつく号令」で敵のバフをすべて解除する（「ふっ、その程度、お見通しだ。」）。生徒に食料を優先して配り、自分は空腹で弱っていた。2章では作戦会議で各校の情報を冷静に説明する
- 見た目の案: 細身で背が高い。銀縁の眼鏡、整えた紺がかった黒髪。制服をきっちり着て、生徒会の腕章。資料のファイル。差し色は青

外見:
```
氷室 怜（ひむろ れい）。男子高校3年生、生徒会長。のちに主人公たちの参謀になる。すべてお見通しの冷たい頭脳。
長身で細身、少しやつれた顔。きちんと整えた紺がかった黒髪、細い銀縁の眼鏡、冷ややかな目。
学ランを一切着崩さずに着ている。左腕に青い腕章（文字は入れない）。
```

| 種類 | ポーズ・表情 |
|---|---|
| 腰より上 | 片手に資料のファイルを持ち、もう片方の手の指で眼鏡を押し上げている。無表情 |
| 全身 | 右を向き、片手を前に差し出して号令をかける姿勢。もう片方の手は背中に回している |

## 柴崎 龍也（しばさき たつや）

- 決まっていること: 男子・2年の別クラスのボス（オープニングの敵）。長身、染めた金髪、耳にいくつものピアス。20人ほどの取り巻きを連れる。下品に笑い、閃を「天城様」と呼んで挑発する。椅子を振り回すような喧嘩
- 見た目の案: 着崩した制服、開いた胸元、ネックレス。パイプ椅子
- 全身は、オープニングの戦闘で相手側（右）に出る。ほかのキャラと同じく右向きで作り、画面で反転させる

外見:
```
柴崎 龍也（しばさき たつや）。男子高校2年生、不良グループのボス。お山の大将。
長身、染めた金髪を逆立て、両耳にいくつものピアス。
学ランをだらしなく着崩し、胸元を開けてネックレスをしている。
```

| 種類 | ポーズ・表情 |
|---|---|
| 腰より上 | 相手を見下して大口を開けて笑う下品な表情。親指で自分を指している |
| 全身 | 右を向き、パイプ椅子を両手で振りかぶっている |
