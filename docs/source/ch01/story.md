# ストーリー会話の一覧（1章・2章・3章）

このファイルは `npm run docs:units` でステージデータ（`data/chapter1/stage.json`・`data/chapter2/stage.json`・`data/chapter3/stage.json`）の `story` から自動生成している。手で編集しない。物語の文を直すときは、ステージデータの文を直して作り直す。

## 読み方

- 文はデータの順に並べた。番号 `#12` は story 配列の添字
- 見出しと見出しの下の説明は、場面の最初の文の `scene`・`sceneNote`（上にまとめる見出しは `sceneGroup`・`sceneGroupNote`）
- 名前は `{hero}`（フルネーム）・`{hero:given}`（下の名前）の書き方を、実際の名前に置き換えている。改行は `\n`
- せりふは `話し手「…」` の形。【演出】は文章以外の効果、【背景】はストーリー画面の背景の絵（`web/public/backgrounds/`）、【BGM】はこの文から流す曲（`web/public/bgm/`）、【選択肢】は文のあとに出す選択肢
- 物語を入れられるきっかけは [concept.md](../spec/concept.md) の「物語を入れられるきっかけ」
