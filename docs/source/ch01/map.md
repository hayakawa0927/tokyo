### マップ（斜め上から見た校舎）
校舎を斜め上から見た立体図で描き、建物や校庭をそのまま押して行き先を選ぶ（参考: `docs/reference-images/校舎の俯瞰図.png`）。この画面の見た目を変えるときは、先に参考画像と見比べる。

#### 配置（1章の校舎）
| 建物 | 場所 |
|---|---|
| 本校舎（3階建て、奥） | 3階: 生徒会室・3年フロア／2階: 2年フロア・図書室／1階: 保健室・1年フロア・購買・食堂・昇降口（各階とも左から この順） |
| 部室棟（2階建て、本校舎の右） | 部室棟。本校舎の2階と渡り廊下でつながる |
| 校庭（手前の左） | 校庭。楕円のトラックを描く |
| 体育館（右手前、平たい屋根の大きな建物） | 体育館 |

- 見える面は 上面・正面・右面。本校舎の正面（長い面）が広く見える角度にする
- 階・部屋の割り当ては、ステージデータのつながり（廊下・階段・渡り廊下）に合わせて決めた。場所やつながりを変えたら、この表と `web/src/MapView.tsx` の形の定義を合わせて直す

#### 表示
- 建物には色を塗らない（明るい灰色。窓を描く）。自陣かどうかは名札の吹き出しの色で見せる
- 名札（吹き出し。場所ごとに、しっぽの先が正面の真ん中を指す）: 自陣（主人公側の場所）は青、それ以外（相手の勢力・無所属）はすべて灰色（#5c6370）で塗り、名前（本拠地は★）、そこにいる部隊の数（いなければ出さない）。マウスを乗せると「場所の名前（勢力の名前）」
- 吹き出しを出すのは、自陣・行ける場所・生徒会室・購買食堂だけ。ほかの行けない相手・無所属の場所には出さない（行き先を選ぶ場面でないときは、自陣と生徒会室・購買食堂だけ）。いつも出す場所は `web/src/MapView.tsx` の `ALWAYS_LABELED`
- 行き先を選ぶ場面（1章の行動）では、行ける場所の輪郭が黄色の点線で動き、吹き出しの縁も黄色になり、黄色の帯で「行ける・〇人まで」を出す（階段・渡り廊下は2人、廊下は4人）
- 選んだ場所は白い枠（面の輪郭と吹き出しの縁）
- 下に凡例: 自陣（青）、それ以外（灰）、行ける場所、★ 本拠地。どの勢力の場所かは、吹き出しにマウスを乗せると出る

#### 操作
- 面か名札を押すと、その場所を選ぶ。もう一度押すと選ぶのをやめる
- 右の「どこへ行く？」の一覧から選んでも同じ（マップと一覧の選択はつながっている）
- 絵の素材は使わず、SVGの図形だけで描く（絵ができたら差し替える）
