## 1. 位置づけ

- 主人公（2年）が、相棒と2人から始めて学校を統一する章。ゲーム全体のチュートリアルを兼ねる
- 主人公＝**天城 閃（あまぎ せん）**（雷のような激しさ。必殺技「雷穿（ライトニング・ピアサー）」）、相棒＝**風間 爽太（かざま そうた）**（風のように自由。必殺技「風鳴（かぜなり）」）。2人の合体技は「双連（そうれん）」
- 1ターン＝1日。自動で遊ばせると5〜7日（平均5.3日）で統一する
- 主人公側の人数は 2人 → 1年を制圧して3人（1年のリーダー）→ 生徒会長を倒して4人（参謀候補）
- 1年のリーダー（桐生 翼）の必殺技「差し入れ」（味方1人の兵を、自分の兵の30%回復。2章と同じ）は、主人公側の仲間になってから使える（1年のボスとして戦う間は使わない。データの `skillOnJoin`）

### 部室棟の手応え
考えないと負ける寄り道。1年を制圧したあと（兵30・毎日全快・合体技あり）に主人公と相棒で行く場合を基準にする。

| 場面 | 目標 | 確認結果（部室棟の戦闘だけを400回） |
|---|---|---|
| 1年を制圧する前（初日: 兵20・10、合体技なし） | 必ず負ける | 0% |
| 1年を制圧したあと、通常攻撃だけ | 7割勝つ | 0%（3部隊とも兵35にした結果。部員26のときは72%） |
| 1年を制圧したあと、必殺技・合体技を使う | 必ず勝つ | 87%（部員26のときは98%） |
| 退却してもう一度（主人公側は全快、部室棟は回復しない。通常攻撃だけ） | 必ず勝つ | 100% |

- 部室棟の主だけ（兵30）のときは、主人公の技（指揮官を直接狙う）と合体技で主のHP4がすぐ削れ、いつ行っても100%勝てた。部員を足して数で押す形にした
- 主人公と1年のリーダーで行く（合体技なし）と、技を使っても数%しか勝てない。連れていくメンバーを考える場面にもなる
- 購買・食堂を取る前に部室棟へ行って負けると、回復できずに購買・食堂にも勝てなくなるおそれがある。そのため、購買・食堂を持っていないときは、出陣の前に相棒が止める（ステージデータの場所の `sortieWarning`。「それでも行く」で行ける）
  - 1日目: 部室棟を行き先に初めて選んだとき、爽太が注意する（物語のきっかけ `select`。1度だけ）: 爽太「部室棟か。あそこは運動バカがわんさかいやがるぜ。この人数だと、ちょっとやばいかもな」。背景は出さず、行き先を選ぶ画面のまま重ねる（物語の `keepScreen`）。1日目は出陣の前の警告は出さない（`sortieWarning.fromTurn: 2`）。2日目からは今までどおり、購買・食堂を持っていなければ出陣の前に止める

## 3.5 物語と説明の流れ

文章の全文は [stage.json](../../data/chapter1/stage.json) の `story` にある。ここには決まった流れだけを書く。

### 文章の書き方（データの約束）
- 会話は `話し手「せりふ」` と書く（画面では話し手の名前を見出しにして出す）。話し手を書かない文は地の文
- 立ち絵（人影）で分かる反応や、「〇〇が言った」のような話し手の説明は地の文に書かない。名前のない生徒たちの声も「2年の男子」「柴崎の取り巻き」などの話し手を付けて、人影で出す
- 人が次々に言い合う場面は、物語の1文に `"rapid": true` を付ける（画面では文字送りを速くし、出し切ったら押さなくても次のせりふへ進む）
- 遊び方の説明は、先頭に `［説明］` を付ける（画面では「説明」の見出しと別の色の枠で出す）
- 物語の1文に `"map": [場所のID…]` を付けると、その文のあいだ画面に地図を出し、その場所を光らせる（空の配列なら地図だけ）。勢力の説明などで使う（2章から）
- 物語の1文に `"freshCast": true` を付けると、その文の始めに立ち絵を全員下げてから出す（前の場面の話し手を残さない）。主人公と相棒の会話が続くときは、画面が主人公を左・相棒を右に並べる（ui-design.md「立ち絵」）。1章では #17（閃が爽太に声をかける）に付けている
- 文の中の `{hero}` `{partner}` `{president}` などは、キャラの名前（フルネーム）に自動で置き換わる。`{hero:given}` は下の名前（閃）。**せりふの話し手と、仲間同士の呼びかけは下の名前**で書く（例: `{partner:given}「{hero:given}、いくぞ」`）。名前をデータに直接書かない（名前を変えるとき、キャラのデータ1か所で済むように）
- モブの名前は、ゲーム開始時に名前のリスト（`data/mob-names.json`）からランダムに付く。物語の文でモブを話し手にするときも、`{first-mob1:given}` のように指揮官IDで書く（「1年の見張り」と直接書かない）。物語で性別が決まっているモブには、ステージデータで `gender` を付ける（1年の見張り・3年のまとめ役・部室棟の主・生徒会委員A・Bは男子。物語の立ち絵を `student-male` にするため）
- 物語のきっかけ（`on`）: start / openingAdvice / skillsUnlocked / openingWon / turnStart / phaseStart / battleStart / comboUnlocked / comboReady / capture / defeated / attackFailed / cleared など
  - `attack`: その勢力が攻めに出たとき（2章から）。`attacker` と、書けば `node`（攻め先）。守る者がいなくて戦わずに取るときも流れる（`battleStart` は戦闘にならないと流れない）
  - `playerBattle`: 主人公側が戦う戦闘の始まり（攻める・守るどちらも。2章から）。書いた条件をすべて満たせば流れる: `node`（戦う場所）・`from`（攻める側の出陣元）・`attacker`・`defender`（攻める・守る勢力）・`foe`（相手の顔ぶれにこのキャラがいる。連戦の2戦目以降の顔ぶれも含む）・`factionHas`（その勢力にこのキャラが全員いる。捕虜・仲間になっていない）・`ours`（自軍の顔ぶれにこのキャラが全員いる）・`notOurs`（自軍の顔ぶれにこのキャラがだれもいない）
  - `itemDamaged`: 倒されて、持っているアイテムの性能が落ちたとき（2章から。1人1度だけ起きる）。`commander`（アイテムを持っていたキャラ）。2章では鮫島が初めて倒されると「カスタムバイクが大破した」
  - `recruited`: 捕虜が説得で仲間になったとき（2章から）。`captive`（仲間になったキャラ）・`faction`（仲間にした勢力）。文の中の `{by}`（`{by:given}`・`{by:family}`）は、説得したメンバーのうち捕虜の説得の決まりを満たした人（なければ知力のいちばん高い人）の名前になる
- 分かれる物語（自軍の顔ぶれで文を変えるなど）は、分かれた文すべてに同じ `"onceGroup"` を付ける。組のどれかが一度流れたら、そのあとは組の文をどれも流さない（`once` だけだと、別の分かれ方の文が次の機会に流れてしまうため）
  - `skillsUnlocked`: オープニングで、封じられていた必殺技が解放されたとき（ステージデータの `opening.skillLock`: 柴崎が2回行動したあと、または爽太が2回行動したあとの閃の番）。戦闘画面に重ねて流す
  - `comboReady`: 解禁される合体技が戦闘の途中で初めて使えるようになったとき。`by`（そのとき番が来たキャラ）で文を分けられる。`by` を書かなければ、だれの番でも流れる。画面では、そこまでの行動の演出が済んでから出す
  - `turnStart`: ターンの冒頭の会話。`turn`（その日だけ）と `owns`（主人公側がその場所を持っていれば）を条件に書ける。`once` と組み合わせると「その場所を取った次のターン」に流せる。2日目の冒頭の会話（食堂へ向かう一行）は `turn: 2` と `once` で入れた

### オープニング
1. プロローグ（ゲーム開始時。大人が消えた朝 → 体育館で2年が分裂して乱闘 → 閃が「俺がやる」→ 柴崎の不良グループ20人が道をふさぎ、11人を倒したところで戦闘へ）
2. 戦闘は途中から始まる（柴崎 龍也: 兵20・HP2/4・速さ5、閃と爽太は兵0）。柴崎に押し込まれる様子の会話のあと、番は速さの順（同じ時刻なら攻める側が先。オープニングは主人公側が攻める側）で回る。はじめは必殺技を選べず、柴崎が2回行動したあとの閃の番で、爽太・閃の会話と［説明］が流れて必殺技が解放される（ステージデータの `opening.skillLock`、物語のきっかけ `skillsUnlocked`）
   - 解放の条件を追加: **柴崎が2回行動する、または爽太が2回行動する**（攻撃・防御など行動の種類は問わない）。どちらか先に満たしたあとの閃の番で解放する（`skillLock.allyActs`）
   - 今の速さ（爽太7・閃5・柴崎5）では、爽太の2回目（時刻28.6）のすぐあとの閃の2回目の番（時刻40）で解放される。柴崎の行動は1回だけ済んだところで、柴崎の2回目より前になる
3. オープニングは決着がつくまで続く戦闘なので、画面に行動の残り回数は出さない
4. 戦闘で倒された者（HP0）は、ふつうの戦闘と同じくHP1で残る

## 4. ルールの要点

### ターンの流れ（1章はフェーズなし）
- 1章には探索・補給・行動のフェーズはない（フェーズは2章から。[concept.md](concept.md) の「ターンの流れ」）
- 1日の流れ: **ターンの冒頭の会話 → 行き先を選ぶ → 行くメンバーを選ぶ → 戦闘** でその日は終わる。「今日はどこにも行かない」も選べる
  - 行き先は、主人公側の場所に隣り合う場所ならどこでも。キャラのいる場所は問わない
  - 行ける人数は、つながりの上限（廊下4、階段・渡り廊下2）
  - 攻めるのは1日1回。探索・補給・休憩・移動はない
- ターンの冒頭の会話は、日（turn）や持っている場所（owns）を条件に入れられる（ステージデータの `turnStart`）。1章で流すのは2日目の会話（場面8）だけで、3日目からは会話なしで行き先選びになる
- 最初のターン（オープニングのあと）だけ、フェーズの前振りを見せる: 探索パートが光る → 相棒「探索つってもな、やることないだろ」→ 行き先選び（補給パートの説明と相棒の一言は、補給フェーズをなくしたので消した）
- 1章の敵はすべて守りに徹するので、主人公側が攻められることはない

### 回復
| 回復するもの | 方法 |
|---|---|
| 指揮官のHP・必殺技の回数（全回復） | 購買・食堂を持っていれば、毎ターンの始めに自動（倒れて退いた者も）。持つまでは回復しない。ただし、購買・食堂を攻めて負けた次の日は、持っているときと同じく全回復する（負けても詰まないように。ステージデータの `rules.troopRecovery.fullAfterLoss`） |
| 兵 | 毎ターンの始めに自動。購買・食堂を持つ勢力（と、前の日に購買・食堂を攻めて負けた勢力）は全快、3年は最大の10%ずつ、それ以外は回復しない |
| 行動回数 | 戦闘が終わると、戦った全員が全快する。毎ターンの始め（各勢力の手番の冒頭）にも、全員が条件なしで全快。残りが0の指揮官は戦闘に編成できない（攻めにも守りにも）。戦闘の途中で0になった者は、その戦闘には残る（攻撃は受けるが行動しない） |

- 1章では食料を使わない（画面にも出さない）
- 兵の上限（主人公側）: はじめ20 → 1年を制圧で30 → 部室棟を制圧で40 → 学校を統一で50（2章で地域を制圧すると100）

### 指揮官の能力
- 攻撃・防御・速さ・知力（1〜8、平均4）、技の回数（1〜4、平均2）、HP（1〜12、平均4）
- 知力は探索にだけ効く（見つかる食料が 知力÷4 倍）。1章では探索がないので効かない

### 戦闘（戦国ランスを参考にした、1部隊ずつ行動する形）
- 速さで行動の間隔が決まる。行動回数はキャラごと（基本3回。天城 閃は4回、風間 爽太は5回）。速い部隊が先に使い切り、遅い部隊は終盤に行動を重ねる
- 1回の行動: 通常攻撃・必殺技・合体技・補助の技・防御・退却のどれか
- **通常攻撃のダメージ** ＝ 兵（10未満は10）×（攻撃 − 防御 ＋ 4）÷ 4 × 兵の数の比率（0.7〜1.3）× HPの倍率 × 補助の倍率 ÷ 3 × ぶれ（±20%）
  - 攻撃と防御が同じで兵も同じなら、3回で倒せる
  - HPの倍率 ＝ 1 −（HPの減少率 ÷ 2）
- **部隊ダメージの技** ＝ 通常攻撃の〇倍（**3倍以下**）。兵の数の不利をどれだけ受けるかは技ごとに決める
- **指揮官を狙う技** ＝ HPに直接ダメージ（幅あり）。敵AIの標的はランダム
- **合体技「双連（そうれん）」**（閃と爽太、どちらの番でも発動）＝ 敵全員の部隊にダメージ（相手の防御で決まる。2章と同じ。concept.md「双連のダメージと回数」）。2人とも行動2回、1戦闘に1回。はじめは封印
- **補助の技** ＝ 味方の攻撃アップ／敵の攻撃・防御ダウン。軍全体に効き、重ねがけできる
- **防御** ＝ 次に自分が行動するまで、受けるダメージが半分
- **退却** ＝ 自軍ごと戦闘をやめる（攻める側なら「攻めきれず」扱い）
- 兵が0になっても指揮官1人で戦う（HPを兵として攻撃。あふれたダメージはHPから減る）。**指揮官のHPが0で部隊が壊滅**
- 攻める側は、守る側を全滅させたときだけ勝ち。決着がつかなければ時間切れ

### 捕虜と勢力の制圧
| 結果（攻めた側から見て） | 場所 | 守る側で倒された固有キャラ | 攻めた側 |
|---|---|---|---|
| 勝利 | 制圧 | 捕虜になる | 攻め込んだ場所に入る（倒された者もHP1で） |
| 引き分け（時間切れ） | 制圧できない | HP1で残る | 全員が出発した場所へ戻る（倒された者はHP1） |
| 敗北（退却・全滅） | 制圧できない | HP1で残る | 全員が出発した場所へ戻る（倒された者はHP1） |

- 捕虜ができるのは、攻めた側が勝ったときだけ。守る側が捕虜を取ることはない。倒されたモブは退場する
- ボスを捕虜にすると、その勢力を制圧（場所・食料・固有キャラがすべて手に入る）
- 味方（主人公側）の固有キャラは捕虜にならない（concept.md）。主人公側の**本拠地（2年フロア）を取られたらゲームオーバー**。1章は敵が攻めてこないので、ゲームオーバーにはならない
- 本拠地の決まりは [concept.md](concept.md) の「本拠地」

### 敵AI（と仲間の自動戦闘）の判断
1. 通常攻撃（自分と次に動く仲間で合計3回まで）で7割以上の確率で倒せるなら通常攻撃
2. 合体技・必殺技で1回で7割以上の確率で倒せるなら、それを使う
3. 補助の技（まだ使っていなければ）
4. それ以外は通常攻撃。狙う相手は、7割が一番弱い部隊（兵＋HPが少ない）、3割はそれ以外からランダム
- 性格: 「ボスを狙う」（1年の見張り）、「技を惜しまない」（3年）
