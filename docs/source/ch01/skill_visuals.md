## 雷穿（ライトニング・ピアサー）

- 使う人: 天城 閃（添付: `amagi-sen_full.png`）。差し色は**黄色**
- 流れ（6枚）: 目のカットイン → 溜め → 踏み込み → 貫く → 決めポーズ → 一枚絵

1枚目（カットイン）
```
1枚目。天城 閃のカットイン。
赤い背景に、斜めに割れたガラスの破片が何枚も散らばり、いちばん大きな破片の中に閃の目元のアップ（フルカラー）が映っている。
鋭く落ち着いた目。瞳に黄色い稲光が映り込んでいる。黒髪の前髪が少しかかる。
ほかの破片には、閃の拳のテーピング・まくった学ランの袖が、それぞれ映っている。差し色は黄色。
```

2枚目（溜め）
```
2枚目。同じ配色で次のコマ。
赤い背景、画面の下3分の1は斜めに切った黒い地面。
画面の左寄りに、黒い影絵の閃が重心を低く落として右を向き、片拳を腰に引いて構えている。学ランのすそがなびく。
引いた拳に黄色い稲妻がバチバチとまとわりつき、拳を中心に白い集中線が放射状に広がる。
画面の右の奥に、敵の黒い影の人型が1人（ほかより一回り大きい、指揮官）。
```

3枚目（踏み込み）
```
3枚目。同じ配色で次のコマ。
影絵の閃が、拳を前に突き出して右へ一直線に突進している。体は前に倒れ込み、ほぼ水平。
後ろには黄色い稲妻の軌跡が左の画面の外から一直線に伸び、黒い地面がえぐれて破片が舞う。
背景の赤には、右へ流れる太い白い速度線。右の奥に大きな敵の影が迫っている。
```

4枚目（貫く）
```
4枚目。同じ配色で次のコマ。いちばん迫力のあるコマ。
影絵の閃の拳が、画面の右寄りにいる大きな敵の影の胸のまん中に突き刺さり、敵の背中側から黄色い稲妻の柱が右の画面の外まで一直線に突き抜けている。
当たったところで白い閃光が爆ぜ、白と黒のインクが四方に飛び散る。
当たったところの近くに、中が空白の大きなギザギザの衝撃の吹き出し（白地に黒の太い縁）。
画面全体がわずかに傾いている。
```

5枚目（白飛び。今の画像は6枚目が05.png、7枚目が06.png）
```
5枚目。同じ配色で次のコマ。
画面のほとんどが真っ白に飛んでいる。中央を、黒く太い稲妻の形の亀裂が左から右へ横切り、亀裂から黄色い光が細くもれる。
画面の端に、割れたガラスのような赤い破片がいくつか舞っている。人物は描かない。
```

6枚目（決めポーズ）
```
6枚目。同じ配色で次のコマ。
赤い背景、画面の下3分の1は斜めの黒い地面。
画面の中央右寄りに、影絵の閃が右を向いたまま、拳を下ろして静かに立っている（振り返らない）。拳から黄色い稲妻の名残が細く立ちのぼる。
閃の後ろ（画面の右端）で、敵の黒い影がインクのしずくのように崩れ落ちていく。
```

7枚目（一枚絵）
```
7枚目。フィニッシュの一枚絵。ここだけ人物をフルカラーで描く。
画面の右寄りに、天城 閃の腰より上。決めポーズ: 体はやや右向きで、黄色い稲妻をまとった拳をこちらへ突き出し、顔はこちらへ向けて口元にわずかな笑み。
背景は、赤・黒・白の割れたガラスの模様と黄色の稲妻の飾り、インクの飛び散り。画面の左3分の1は暗い灰色に沈ませる（あとで文字を重ねるため、何も描かない）。
```

## 双連（そうれん）

- 使う人: 天城 閃と風間 爽太の合体技（添付: `amagi-sen_full.png` と `kazama-sota_full.png`）。差し色は**閃が黄色・爽太が緑**
- 流れ（8枚）: 2人のカットイン → 背中合わせ → 飛び込み → 乱打1 → 乱打2 → 同時の一撃 → 決めポーズ → 一枚絵

1枚目（カットイン）
```
1枚目。天城 閃と風間 爽太の合体技のカットイン。
赤い背景に、割れたガラスの破片が散らばる。上下に並ぶ2枚の大きな破片の、上の破片に閃の目元のアップ（鋭い目、瞳に黄色い光）、下の破片に爽太の目元のアップ（いたずらっぽく笑った目、瞳に緑の光）が映っている。どちらもフルカラーで、顔は1人1つだけ。
ほかの小さな破片には顔を描かず、閃の拳のテーピング・爽太の緑のヘッドホンを映す。差し色は閃が黄色、爽太が緑。
```

2枚目（背中合わせ）
```
2枚目。同じ配色で次のコマ。
赤い背景、画面の下は斜めの黒い地面。画面の左寄りで、影絵の閃と爽太が背中合わせに立っている。
閃は拳を握って構え、拳に黄色い稲妻。爽太は肩にかけた学ランがなびき、足もとに緑のつむじ風。
右の奥に、敵の黒い影の人型が5〜6人、横に並んでいる。
```

3枚目（飛び込み）
```
3枚目。同じ配色で次のコマ。
影絵の閃と爽太が、左から右へ敵の群れに飛び込んでいる。閃は低く地面すれすれに、爽太は高く宙を跳ぶ。
閃の後ろに黄色い稲妻の軌跡、爽太の後ろに緑の風の軌跡が、2本並んで右へ伸びる。右に敵の影の群れ。太い白い速度線。
```

4枚目（乱打1）
```
4枚目。同じ配色で次のコマ。
赤い背景の中で、影絵の閃と爽太が敵の影の群れをめった打ちにしている。画面全体に乱戦。
閃は拳、爽太は回し蹴り。白い鋭い打撃の線が何十本も交差し、あちこちで白と黒のインクがはじける。
中が空白のギザギザの衝撃の吹き出しを3つ（大・中・小）、ばらばらの位置に。敵の影はのけぞったり宙に浮いたりしている。
```

5枚目（乱打2）
```
5枚目。同じ配色で次のコマ。4枚目と構図を変える。
画面を斜めに3つの区画に割り、それぞれに別の瞬間を描く（漫画のコマ割りのように）。
上の区画: 閃の影絵の拳が敵の影の顔に入る。黄色い火花。
中の区画: 爽太の影絵が敵の影を投げ飛ばしている。緑の風の筋。
下の区画: 敵の影が2人まとめて吹き飛ぶ。
区画のあいだは白い太い線。中が空白のギザギザの衝撃の吹き出しを2つ。
```

6枚目（同時の一撃）
```
6枚目。同じ配色で次のコマ。いちばん迫力のあるコマ。
画面の中央で、影絵の閃の拳と爽太の跳び蹴りが、同じ1点（敵の影の群れのまん中）に同時に叩き込まれる。
当たったところから、黄色と緑が混ざった大きな白い爆発が放射状に広がり、敵の影がすべて外へ吹き飛ぶ。
画面いっぱいの太い集中線。白い閃光で画面の半分が白く飛んでいる。
```

7枚目（決めポーズ）
```
7枚目。同じ配色で次のコマ。
赤い背景、画面の下3分の1は斜めの黒い地面。画面の中央に、影絵の閃と爽太が並んで着地している。
閃はまっすぐ立ち、拳を下ろしている。爽太は片膝をついて着地し、肩の学ランをかけ直している。
2人の後ろ（画面の右）で、敵の影の群れがインクのしずくのように崩れ落ちていく。
```

8枚目（一枚絵）
```
8枚目。フィニッシュの一枚絵。ここだけ人物をフルカラーで描く。
画面の右寄りに、天城 閃と風間 爽太の腰より上を並べる。2人そろった決めポーズ: 閃はやや前で、黄色い稲妻をまとった拳をこちらへ突き出し、静かな表情。爽太はその少し後ろで、閃の肩に腕を乗せ、もう片手でピースサインを突き出して歯を見せて笑う。
背景は、赤・黒・白の割れたガラスの模様に、黄色の稲妻と緑の風の飾り、インクの飛び散り。画面の左3分の1は暗い灰色に沈ませる（あとで文字を重ねるため、何も描かない）。
```

## 風鳴（かぜなり）

- 使う人: 風間 爽太（添付: `kazama-sota_full.png`）／差し色: 緑

```
技「風鳴」の絵コンテ（全6枚）。使う人は風間 爽太（添付の画像）。差し色は緑。
1枚目（カットイン）: 赤い背景に割れたガラスの破片が散らばる。いちばん大きな破片に爽太の目元のアップ（フルカラー。余裕のある笑み、瞳に緑の光）。ほかの破片に、首の緑のヘッドホン・肩に引っかけた学ラン。
2枚目（構え）: 赤い背景、下3分の1は斜めに切った黒い地面。左寄りに影絵の爽太が右を向き、片足に重心を乗せて体を大きくひねる。足もとから緑のつむじ風が巻き上がり、学ランがなびく。右の奥に敵の黒い影が1人。
3枚目（突風）: 影絵の爽太が回し蹴りを振り抜き、蹴りの軌跡から緑の暴風が右へ吹き出す。太さの違う白と緑の風の筋が何十本も右へ流れ、ちりが飛ぶ。
4枚目（なぎ払う）: 渦を巻く暴風が右の敵の影を飲み込み、宙へ巻き上げる。中が空白のギザギザの衝撃の吹き出し。画面全体が右へあおられて傾く。
5枚目（決めポーズ）: 赤い背景、斜めの黒い地面。影絵の爽太が着地し、肩の学ランを掛け直す。後ろ（右）で敵の影が風に散らされ、インクのしずくのように崩れる。緑の風の名残がたなびく。
6枚目（一枚絵）: 爽太の腰より上（フルカラー）。決めポーズ: 体をひねって片手を前に突き出し、指を2本立てる。もう片手は頭の後ろに回し、人懐っこい余裕の笑み。背景は赤・黒・白の割れたガラスに、緑の風の渦の飾りとインクの飛び散り。
```

```
技「差し入れ」の絵コンテ（全5枚）。使う人は桐生 翼（添付の画像）。差し色は暖かいオレンジ。

3枚目（投げる）: 影絵の翼が袋を振り抜き、パン・おにぎり・から揚げ・弁当・ラーメンのカップが回りながら放物線を描いて右へ飛んでいく（食べ物だけはフルカラーで描いてよい）。

```

## 凍てつく号令（いてつくごうれい）

- 使う人: 氷室 怜（添付: `himuro-rei_full.png`）／差し色: 氷の水色

```
技「凍てつく号令」の絵コンテ（全5枚）。使う人は氷室 怜（添付の画像）。差し色は氷の水色。
1枚目（カットイン）: 赤い背景に割れたガラスの破片。大きな破片に怜の目元のアップ（フルカラー。冷ややかな目、銀縁の眼鏡のレンズに氷の結晶が映る）。ほかの破片に、青い腕章・資料のファイル。
2枚目（号令）: 赤い背景、斜めの黒い地面。左寄りに影絵の怜が右を向き、片手を前に差し出して号令をかける。もう片手は背中に回す。足もとから白い霜が右へ広がる。右に敵の影が3人並び、どの影も赤く光る鎧のような光（強化）をまとっている。
3枚目（凍る）: 画面の四隅から水色の氷の筋がピキピキと張り、敵の影たちのまとう光の鎧が白く凍りつく。画面の色が少し抜け、霜が濃くなる。
4枚目（砕ける）: 凍った光の鎧が粉々に砕け、氷のかけらが水色にきらめきながら飛び散る。敵の影たちは無傷のまま、あっけにとられて立ち尽くす。
5枚目（一枚絵）: 怜の腰より上（フルカラー）。決めポーズ: 体を半身にして、片手の指で眼鏡を押し上げ、もう片手を横へ払うように伸ばす。表情は無表情のまま、レンズが白く光る。背景は赤・黒・白の割れたガラスに、水色の氷の結晶と霜の飾り。
```
