### 場面3: 曳舟が初めて攻めに出る（きっかけ `attack`・一度だけ）
曳舟が初めて攻めに出たとき（攻め先はどこでも。守る者がいなくて戦わずに取るときも）に流れる。ユーザーの骨子をもとに、ちょっと頭が悪めで勢いのいい集団にした。特攻隊長「頭ぁ、行くんですかい！？」→ 鮫島「ここから俺たちの爆走伝説の始まりよ！」→ 夜叉會の男子「本校の守りはどうしますかい？」→ 鮫島「守りてえ奴に守らせりゃいい」「俺たちの目標は常に前だ、前だけを見ろ、前だけ進め、後ろは考えるな！」→「ひー、お頭、かっけえ！！」「そこに惚れる、憧れるぅ！」
- きっかけ `attack`（攻めに出た）を新しく作った。`battleStart`（戦闘の始まり）は守る者がいないと流れないため。`node` を書かなければどこを攻めても流れる
- 物語の「特攻隊長」は曳舟の特攻隊長（`SPEAKER_ALIAS`）。特攻隊長はステージデータで男子に決めた（画像を `student-male` にするため。付く名前も男子の名前になる）

## 勢力の思考（2章・3章で同じ思考を使う）

全勢力（主人公側を含む）を [src/core/ai-ch2.ts](../../src/core/ai-ch2.ts) の同じ考え方で動かし、勢力ごとの性格で違いを付ける。性格は [src/sim-ch2.ts](../../src/sim-ch2.ts) の `PERSONALITY`。

| 勢力 | 性格 | 攻める条件 |
|---|---|---|
| 主人公側 | 勝てそうなら積極的に攻める。**シミュレーションでは、ほかの勢力のAIの行動を予測したうえで最適な行動を選ぶ**（下の「主人公側の先読み」。プレイヤーも相手の動きを読んで動くため）。`--player=plain` で、ほかの勢力と同じ思考 | 勝つ確率50%以上、または削る作戦 |
| 曳舟（暴走族） | 勝てそうなら積極的に攻める。鮫島と特攻隊長は攻めを優先する（守りに残す部隊に選ばず、攻めの顔ぶれの先頭に入れる。`leaders`）。陽動はせず、侵略は本命の部隊だけで使う（`noFeint`） | 勝つ確率40%以上、または削る作戦 |
| 連合 | 南の4校を統一するまでは南だけを攻め、統一したら北へ。轟・月詠・紅林は拠点の守りを最優先にし、隣の敵が連合の拠点を攻めて勝つ見込み（見積もり）が50%以上なら、攻め・説得に出さない（`homeGuard`）。獅堂・黒鉄・強モブ・ほかのモブは攻めに使う。**緑町学園が攻められたときは、轟・月詠・紅林を守りに最優先で入れる**（ステージデータの勢力の `defensePriority`。残りの枠は兵の多い順。兵が同じならデータに書いた順）。**横網学院が攻められたときは、轟・獅堂を最優先で入れる**（1戦目は 轟・獅堂・月詠・紅林・黒鉄、2戦目以降がモブ）。**攻めの顔ぶれは獅堂・黒鉄を先頭に入れる**（`vanguard`。守りに残す部隊の選び方は変えない）（物語で「緑町学園は轟・月詠・紅林、横網は他校を攻めるために獅堂・黒鉄」としたため） | 勝つ確率60%以上 |
| 錦糸（相撲部） | 守るだけ | 攻めない |
| 白鬚・吾嬬・竪川 | 勝てそうなら攻める | 勝つ確率60%以上 |

- **勝つ確率の見積もり**: 攻める前に、その顔ぶれで実際の戦闘の計算を8回試す（乱数はゲームの乱数を使わず、ターンと場所から作る）。戦闘上限と連戦（守る側の先制を含む）も入れて計算する。守る側の顔ぶれは、NPCの守りの決まり（concept.md「NPCの守り」。陽動か本命かを見分けて、防げるだけ出す）で見積もる。偵察を使う章では、このターンに偵察していない相手は兵・HPが満タンとみなす
- **侵略の回数**: 1ターン3回
- **攻めの組み合わせ**（`planAttacks`）: 侵略の回数を、どの学校に何回、陽動（残っている一番弱い部隊1つ）と本命（残りから強い順）のどちらで使うかを全部の組み合わせから選ぶ。点数は concept.md「AIの攻めの組み合わせ」。攻めを1つ実行するたびに、実際に出てきた守りを見て残りを決め直す（`react`）。それまでは、点数の高い攻め先から1つずつ選んでいた
- **偵察**: 力づくでは勝てそうにない攻め先を1つ選び、攻めの顔ぶれに入らない部隊のうち知力の高い順に、成功率90%に届くまで（3人まで）出す。70%に届かなければ偵察しない
- **意思決定**: 全勢力がターンの始めの状態を見て決める（rules.simultaneous）。ほかの勢力の攻めの結果は見ない
- **勝てない相手を削る**（全勢力）: 戦闘の中で途中で引く判断（concept.md「勝てない相手から引く」）を入れて見積もり、勝てなくても「相手の失う兵 − 自分の失う兵 × 重み」が30以上なら攻める。点は その値 ÷ 20（最大9）。重みは食料が1ターンの収入の3倍以上なら1、少なければ1.5
- **守りに残す部隊**: 自分の拠点のうち、いちばん大きい脅威（隣の敵の勢力が本拠地から出せる戦力）の7割に届くまで、弱い部隊から攻めに出さずに残す。必ず1部隊以上残す。ボス（主人公側を除く）は攻めに出ない。隣の敵が実際に攻めてくる性格かどうかは見ない（白鬚・吾嬬のように攻めない勢力も脅威に数える）。攻めを優先するキャラ（曳舟の鮫島・特攻隊長）は残さない
- **主人公側の先読み**（シミュレーション用。`makeForesightAi`）: ターンの始めに、ほかの勢力のAIの行動を同じ思考で予測する。候補（本拠地に残す部隊を弱い順に0〜2部隊にした攻めの組み合わせと、攻めないこと）ごとに、予測した行動と一緒にこのターンの行動フェーズをなぞり（乱数1通り。ほかの勢力は予測した指示のまま決め直さない）、結果の点数がいちばん高い候補を選ぶ。点数は、本拠地を取られたら最悪、それ以外は「持っている学校の価値 + 自軍の兵 + 敵の減った兵 × 0.5」。偵察の決まりは当てない（本当の状態を見る）。1ターンの判断に約3秒かかる
- **攻める道**: 本拠地から出ていくときは、いちばん多くの部隊で攻められるつながりを通る
- **移動**: しない（ユニットは本拠地にいる）
- **食料の使い道**: 1. 兵の補充（最優先）→ 2. モブの補充 →（3. 説得は食料を使わない）
  - 拠点を奪う・守るのに戦力が要るときは、モブの補充と食料でのHPの回復を蓄えに関係なく行う
  - 要らないときは、モブの補充は食料を50以上残せる場合だけ。HPの回復は食料が100以上なら食料で、100未満なら攻められそう・攻めるチャンスがあるときだけ食料で、それ以外は休憩で回復する
  - 守りのためのモブの補充は、本拠地の部隊が兵を満たしていて、自分の拠点のどこかが攻められそうなときだけ
- **説得**: 本拠地の守りが残る場合だけ、知力のいちばん高い者が1ターンに1人を説得する。成功率は知力×10%
- **兵科**: 変えない（初期の兵科のまま）

## 台本（--plan）

[src/tools/ch2-plans.ts](../../src/tools/ch2-plans.ts)。業平・曳舟・連合の行動フェーズの攻め先だけを台本で決め、補給・探索・ほかの勢力は上の思考のまま。台本の段階は、ゲームの状態（どの学校を持っているか）から決める（取られた学校は、順番の早いものから取り返しに行く）。

| 勢力 | 台本 |
|---|---|
| 業平 | 1. 吾嬬か白鬚を攻める → 2. 戦力を回復したら、もう一方 → 3. 曳舟 → 4. 戦力を回復したら錦糸 → 5. 錦糸を取ったら、連合を倒すための最適な行動（上の思考）。`--plan=azuma-kinshi` は 吾嬬 → 錦糸 → 白鬚 → 曳舟 の順 |
| 曳舟 | 1. 業平と逆の学校（業平が吾嬬なら白鬚）を攻める → 2. 戦力を回復させる → 3. 牽制: 主人公側の本拠地以外の拠点へ、2部隊で攻める。鮫島と特攻隊長は必ず攻めの顔ぶれに入れる |
| 連合 | 1. 竪川を攻める → 2. 戦力を回復させる → 3. 錦糸を攻める → そのあとは上の思考。轟・月詠・紅林は上の性格の決まりで守りに残ることがある。攻めは獅堂・黒鉄・強モブ・ほかのモブで行う |

- 「戦力を回復した」の基準: 攻める部隊の兵が合わせて上限の8割以上、HPが全員満タン。届くまでは攻めない（HPが減った者は休憩）
- 攻めの顔ぶれは、使える部隊を強い順に、いちばん多くの部隊で攻められるつながりの上限まで

## 実装で決めた扱い

- 守る部隊を出せなければ（全員が出払っている・行動回数が残っていない）、戦わずに取られる。本拠地なら勢力は消滅する
- 志願の日に勢力の部隊の数が上限（6 × 学校の数）に達していたら、空くまで志願は待つ。その前に学校を取られたら来ない。志願したモブはそのターンから動ける
- モブの補充は本拠地に出てくる。1ターンに持っている学校の数まで、勢力全体の部隊の数が「6 × 学校の数」未満のとき
- 補充した数が生産の最大数を超えたら（学校を失ったとき）、補充できなくなるだけ
- 補充したモブの名前は、まだ使っていない名前から選ぶ。リストを使い切ったら、今いるキャラと重ならない名前を使い回す
- 戦闘中の技の選び方は concept.md の「戦闘AIの範囲の技・全員に当たる合体技の使い方」
- NPCの守り: 足した守りの戦力が攻め手の戦力の半分に届くまでは、防げる見込みを試さずに次の部隊を足す（見積もりを軽くするため。phases.ts の `HOLD_MIN_RATIO`）
- AIの攻めの組み合わせ: 陽動の部隊は、勝てないと見てすぐ退くので兵を失わないものとして見積もる
- シミュレーションだけの指定（`npm run sim:ch2`）: `--first=学校` 業平が1日目だけその学校を攻める、`--hold-day1` そのとき守る側は逃げない（ステージのルール `holdNodes`）、`--actions=2` 1ターンの侵略の回数を変える、`--troops` ターンごとの勢力の兵の表
