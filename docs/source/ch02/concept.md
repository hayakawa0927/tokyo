- **2章のモブの能力**: モブは攻撃・防御・速さ・知力・HPすべて4、強モブはすべて5。どちらも行動回数3、必殺技なし。**兵科「後」のモブ・強モブは防御-1**（モブ3・強モブ4。初期配置のキャラのデータで下げている）。**兵科「中」のモブ・強モブは攻撃-1**（モブ3・強モブ4。初期配置に「中」のモブはいない）
  - **特攻隊長**: 強モブの派生。曳舟に1人。攻撃6・防御5・速さ6・知力5・HP6、行動回数6
  - **特攻隊長の必殺技**: 「特攻（ぶっこみ）」: 敵の前衛全員の部隊に、通常攻撃の1倍のダメージ（前衛がいなければ後衛全員）。当てる部隊ごとにダメージを計算し、兵の数の不利は通常攻撃と同じだけ受ける（断絶と同じ扱い）。行動2回、何度でも使える。相手の前列にしか当たらない技なので、後列からは使えない。使うときのセリフは技の名前だけ「特攻（ぶっこみ）！」（ステージデータでは `name: "特攻", reading: "ぶっこみ", shout: "特攻！", type: "troops", area: "front", multiplier: 1, outnumberedPenalty: 1, cost: 2`）
    - 効果の確認: 曳舟の4部隊（鮫島・特攻隊長・強モブ2人）で攻めたとき、白鬚に 0% → 6%（残りは引き分け。白鬚が失う兵 157 → 221）、吾嬬に 69% → 98%
  - **曳舟の強モブ（2人）の必殺技**: 「ガソリン満タン」: 味方1人（自分を含む）の兵を10回復（固定。部隊の兵の上限まで）。行動1回、何度でも使える（ステージデータでは `type: "heal", amount: 10, cost: 1`）
- **モブの名前**: 「山田 太郎」のような、ありふれた名前にする。名前のリスト（男子213人・女子87人、合わせて300人）は `data/mob-names.json`。1章・2章のモブ・強モブには、ゲーム開始時に、ここからランダムに重ならないように選んだ名前を付ける（`src/core/names.ts`。乱数は `createRng`、シードはゲームのシード）。物語で性別が決まっているモブ（1年の見張り・3年のまとめ役は男子）は、ステージデータの `gender` でその性別の名前から選ぶ。物語の文では `{first-mob1:given}` のように書き、せりふの話し手は下の名前になる
