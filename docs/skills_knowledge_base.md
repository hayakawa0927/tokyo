# 必殺技・合体技

元ネタ: `docs/source/ch01/` の `units.md`（技の中身）・`skill_visuals.md`（技の見た目）。**数値（倍率・回数）は書かない**。小説では、どう見えるか・いつ使うかだけを決める。
必殺技は、**能力者の特殊能力**。必殺技を持つキャラは全員、能力者（2026-11-17 に決めた。はっきり超常の力として描く。くわしくは `world_knowledge_base.md` の「能力者」）。

本文の技名は `|技名《ルビ》` の形にする（例: `|雷穿《ライトニング・ピアサー》`）。

## 天城 閃 — 雷穿（ライトニング・ピアサー）
- 使うときのセリフ: 「一点突破だ、貫け、雷穿！」
- 相手の頭（リーダー）を一点に狙って打ち抜く。周りの取り巻きを相手にせず、まっすぐ頭に届く
- 1章での型: 相手の拳を真正面から受け（「軽いな」）、腹への一撃で体をくの字に折り、膝蹴りで顎、最後に渾身の右ストレート（柴崎戦）
- 初めて使うのはオープニングの柴崎戦。爽太に「やるのか？」と促されてから
- 見え方: 重心を低く落とし、拳を腰に引いて溜める → 一直線に踏み込む → 相手の胸の真ん中を打ち抜く。打ち終わると拳を下ろして静かに立ち、振り返らない。後ろで相手が崩れ落ちる
- 能力の見た目: 拳に本物の黄色い稲妻がまとわりつき、突進の跡に稲妻の筋が残る。差し色は黄色

## 風間 爽太 — 風鳴（かぜなり）
- 使うときのセリフ: 「薙ぎ払え、風鳴！！」
- 身軽さで集団の中を駆け抜け、まとめて薙ぎ倒す。数を相手にする技
- 見え方: 片足に重心を乗せて体を大きくひねる → 回し蹴りを振り抜き、周りの相手をまとめて吹き飛ばす → 着地して、肩の学ランを掛け直す
- 能力の見た目: 足もとから緑のつむじ風が巻き上がり、回し蹴りから暴風が吹き出す。差し色は緑

## 桐生 翼 — 差し入れ
- 使うときのセリフ: 「腹が減ってはなんとやら、ってね！」
- 仲間の連中に食べ物を配って立て直す。仲間になってから使う（1年のリーダーとして戦うときは使わない）
- 見え方: 購買のパンの袋を大きく振りかぶり、パン・おにぎり・から揚げ・弁当・カップ麺を仲間へ放り投げる。受け取った者が食べて立ち直る。決めの仕草は、袋を高く掲げ、人差し指を相手に突きつけるニヤリ顔
- 能力（2026-11-17 に決めた）: **翼が手渡した食べ物を食べると、疲れや傷みが一気にやわらぐ**。受け取った者の体から、暖かいオレンジの光が昇る
- 1年のリーダーとして戦うときに使わない理由は、書くときに決める（案: 自分の飯を人に割きたくなかった。「俺の飯」）
- 差し色は暖かいオレンジ

## 氷室 怜 — 凍てつく号令（いてつくごうれい）
- 使うときのセリフ: 「ふっ、その程度、お見通しだ。」
- 相手の勢い・士気の高まり、場の有利（陣取り）を、号令ひとつで打ち消す
- 見え方: 片手を前に差し出して号令をかけ、もう片手は背中に回す。相手は傷ひとつ負わないまま、乗っていた勢いだけが止まり、あっけにとられて立ち尽くす。決めの仕草は、指で眼鏡を押し上げ、もう片手を横へ払う。表情は変えない
- 能力の見た目: 足もとから霜が広がり、相手の勢いを凍らせて砕く（相手の体は傷つけない）。差し色は氷の水色

## モブの技

モブは能力者ではない。下の技は能力ではなく、号令・連携・数で押すといった集団の戦い方として描く。

| 使う人 | 技 | セリフ | 見え方 |
|---|---|---|---|
| 1年の食堂番 | 腹ごしらえの突撃 | 「食ったら動く！ 突撃だー！」 | 食べてから一斉に突っ込む |
| 3年 | 3年の圧 | 「先輩に逆らうとは、いい度胸だな」 | 体格と人数で押しつぶす |
| 生徒会委員 | 委員の連携 | 「委員会、配置について！」 | 持ち場を詰めて陣を組む |
| 部室棟の主 | 部活の結束 | 「部活の絆、見せてやれ！」 | 号令で部員全員の動きがそろう |

## 合体技 — 双連（そうれん）（閃と爽太）
- 2人で同時に仕掛け、囲んでいる相手をまとめて崩す。格闘の連携技
- 見え方: 背中合わせに構える → 閃は低く地面すれすれに、爽太は高く跳んで群れに飛び込む → 閃は拳、爽太は回し蹴りと投げで乱打 → 最後に、閃の拳と爽太の跳び蹴りを同じ1点に同時に叩き込み、周りの相手がまとめて吹き飛ぶ → 閃はまっすぐ立ち、爽太は片膝をついて着地し、肩の学ランを掛け直す
- 能力の見た目: 閃の稲妻と爽太の風が並んで走り、最後の一撃で黄色と緑が混ざった爆発になる
- 初めて使うのは購買・食堂の戦い。囲まれて守りを固め、相手が油断した隙に、どちらかが切り出す
  - 切り出す側（閃なら「今だ」、爽太なら「今だ、空いた！」）「（相手の名前）、いくぞ、合わせろよ！」 もう一人「任せろ！」
