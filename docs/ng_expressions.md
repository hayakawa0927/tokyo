# NG表現リスト（なんとなくの言葉）

意味がわかりそうで実際には不自然な表現。生成後に照合すること。

出どころ: 奮闘記の `ng_expressions.md` を写して始め、この世界に合わせて例を直した。「（ゲームの文体ルールから）」とある表は、作者がゲームの文用に足したもの（2026-11-17 に取り込んだ）。

---

## 身体動作・喧嘩の描写

| NG表現 | 問題点 | 代替例 |
|--------|--------|--------|
| 足の重心がさらに沈む | 「重心が沈む」は不自然 | 腰が、さらに落ちた |
| 体が低く沈む | 「沈む」を動作に使わない | 腰を落とす |
| 体を沈め、回す | 曖昧な動作描写 | 膝を曲げ、軸をずらす |
| 肩を回し身を捻る | AI的な連続動作列挙 | 具体的な動作を一つに絞る |
| 着地した左肩 | 肩は着地しない | 受けた左肩 |
| 軌道を切る | 「軌道を切る」は使わない表現 | 拳をかわす／拳を流す |
| 空気が爆ぜる | 空気は爆ぜない | 衝撃音・擬音で代替 |
| 空気が〇〇を運ぶ | 擬人化が不自然 | 削除するか具体的な描写に（風が、焦げた匂いを運んできた） |

## 情景・状況描写

| NG表現 | 問題点 | 代替例 |
|--------|--------|--------|
| 周囲の景色だけが壊れていく | 「景色が壊れる」は不自然 | 窓ガラスが割れ、机が倒れる、など壊れていく物を具体的に |
| 土煙が広がる | 漠然としている | 土煙が舞い上がった、など具体的に |
| 体育館全体が呼吸を始めた | 擬人化として成立するかもしれないが、一般的に使わない表現 | 別の表現で雰囲気を出す（照明が一斉に点いた） |
| 声が（静寂・廊下など）に落ちる | 「沈黙が落ちる」との混同。声は本来「響く」「届く」ものであり「落ちる」とは言わない | 声が響いた／声が静寂を破った |

## 人物描写

| NG表現 | 問題点 | 代替例 |
|--------|--------|--------|
| 二人の眼光が同時に強まった | 「眼光が強まる」は大げさで不自然 | 二人が、目を据えた |
| 息を詰める | 標準的な慣用句ではない。「息を止める」「息を潜める」などと混同したAI生成表現 | 息を止める／呼吸を殺す／歯を食いしばる |
| 声を落とす | 不自然な日本語（著者判断）。声量調整の描写として使わない | 声を潜める、または単に「言った」「口を開いた」に置き換える |
| まばたきをする余裕が消えていた | 疲弊・限界の描写として迂遠 | 息が荒くなっていた／限界が近い |
| 脇腹に血が滲む（打撃ダメージ） | 打撃で脇腹から出血はしない。物理的におかしい | 息を吸うたびに痛んだ、など呼吸・動作で表現する |

| NG表現 | 問題点 | 代替例 |
|--------|--------|--------|

| ごっそり目減りする | 直前で「じわじわ」と描写した減り方と矛盾する誇張表現 | 描写の程度（急激／緩やか）を前後の文脈と揃える |

## 1話で1回まで（ゲームの文体ルールから）

使ってもよいが、1話で1回まで。続く話で同じ言い回しを続けない（ゲームでは「1つの章で1回まで」）。

| 表現 | 代わりに |
|---|---|
| 空気が変わった／空気が張り詰めた | 誰かが黙る・手を止める・目をそらす |
| 沈黙が落ちた | 「誰も喋らない。」や、その場の音（腹の鳴る音、上履きの擦れる音など） |
| だと思った（〜っす） | ほかの返し方。言う人を毎回変える |
| 〜の流儀 | そのまま言う |
| ただし、〜 | 「でも」「それと」、または文を分ける |

## 決め台詞（ゲームの文体ルールから）

| 表現 | 問題点 | 代わりに |
|---|---|---|
| 場面の終わりの 閃「行くぞ」 | 同じ締めが続きやすい | 閃が黙って動く、別の人が先に動く、閃が具体的なことを言う（「爽太、裏から回れ」） |

## 形の決まり文句（ゲームの文体ルールから）

| 表現 | 問題点 | 代わりに |
|---|---|---|
| 「AではなくB」「〇〇。だが、〜」 | 対比で気取った言い方になる | 言いたいほうだけ書く |
| 場面・話の最後の「〜が始まった」「〜が動き始めていた」「〜だった」 | まとめ・予告で締めている | 行動かセリフで終える |
| うまい呼び名・二つ名（「腹ペコのやつら」「北の覇王」） | ラベルで済ませている | そのまま言う |
| 格言・一般論（「〜は〜だ」「いつの時代も〜」） | 説教くさい | その場の具体的なもので言う |
| 女子の「〜わ」「〜わよ」 | お嬢様以外が使うと不自然 | お嬢様・年上らしさを出すキャラだけに使う |

## 説明のしすぎ（ゲームの文体ルールから）

| 表現 | 問題点 | 代わりに |
|---|---|---|
| 〜という顔だ／〜という顔をした（毎回） | 気持ちの説明 | 動作を1つ書く |
| 〜したかったんだろ（いちばん最後のツッコミで理由を言い当てる） | 落ちを説明している | 言い当てずに終える |

## 補足ルール

- **既存ファイルに同じ表現があっても正解とは限らない**（過去に使われた表現も問題のある場合がある）
- **意味がわかる ≠ 自然な日本語**。声に出して違和感がないか確認する
- ダメージは「血が滲む」より「息を吸うたびに痛んだ」「奥歯を噛んで流した」など動作・感覚で表現する

## 表現を書く前の検証手順（このリストへの丸暗記より優先）

このリストは事後に見つかった個別事例の記録に過ぎない。**新しい比喩・感覚表現を書く前**に、以下を自問すること。編集の規模（1行差し替えでも）に関わらず必須。

1. **その言い回しは辞書的・慣用句として実在するか、それとも似た表現からの連想で「それっぽく」作った言い方か**を自問する。後者の疑いがあれば使わない。
   - 例：「持ってかれる／持っていかれる」は本来、意識・注意・目・時間など「何かに気を取られて奪われる」対象に使う言葉（例：「話に気を持ってかれる」）であり、体力のように減っていくものの消耗には使わない。「体力が持ってかれる」も含めて誤用
2. **減っていくもの・量で扱うもの**（体力・空腹・食料の残りなど）には、その性質に対応した正確な動詞を使う。消耗＝減る／削られる、のように語の意味範囲を守る。視覚・光学の比喩（絞る＝ピント、像を結ぶ＝結像）を、ほかの意味に転用しない
3. **強調の程度が前後の文脈と矛盾していないか**確認する（「じわじわ」と言った直後に「ごっそり」「急速に」と書かない）
4. 上記の自問で不安が残る表現は、曖昧な比喩ではなく具体的な動作・物・現象で言い換える
5. 新たに気づいた違反パターンは、その場で本ファイルの表に追記する（再発防止の補助であり、事前検証の代わりではない）
