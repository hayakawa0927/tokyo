## 業平高校（1章）

- 本校舎は3階建て。ほかに部室棟・校庭・体育館
- 2年の棟と1年の棟は**渡り廊下**でつながる。3年フロアへは**階段**を上る（狭いので、一度に大勢は上がれない）
- 部室棟へも渡り廊下で行く

| 場所 | 1章のはじめの持ち主 | 様子 |
|---|---|---|
| 2年フロア（2年の教室棟）・図書室 | 2年（閃たち） | 2年の本拠。2日目の朝は、教室の床で寝た者が多い |
| 1年フロア・保健室・昇降口 | 1年 | |
| 購買・食堂 | 1年 | 1年の本拠。入り口に机と椅子のバリケード。食堂の中は段ボール箱（パン・カップ麺・ジュース）。奥に厨房（米・肉・冷凍庫） |
| 3年フロア | 3年 | 廊下に机を積んだ壁がいくつも並ぶ |
| 生徒会室 | 生徒会 | 前の廊下に長机を横倒しにして並べている。倉庫の鍵は生徒会が持つ |
| 部室棟 | 運動部 | 汗と湿布と使い込まれた防具のにおい。廊下にジャージ姿の部員が並ぶ |
| 校庭 | なし | 1日目、生徒たちが集まって泣いたり叫んだりしていた |
| 体育館 | なし | 1日目、2年が集まって乱闘になった場所 |

- 中庭から、1年・2年・3年の集団が見える

## 学校の外（1日目に分かったこと）

- 駅前・コンビニ・駅・交番は無人。バスは止まっている。車だけ残っている
