## 業平高校（1章）

- 校舎は、2年と3年の本校舎と、1年の棟に分かれる。ほかに部室棟・校庭・体育館（2026-11-17 に決めた。ゲームのマップは1年も本校舎の1階だが、小説では物語の文の「2年生の棟と1年生の棟をつなぐ渡り廊下」に合わせて別の棟にした）
  - 本校舎（3階建て）: 3階 生徒会室・3年フロア／2階 2年フロア・図書室／1階 昇降口
  - 1年の棟: 1年の教室・保健室。棟を抜けた先に購買・食堂がある（#136「1年生の棟を抜け、購買と食堂のある一角へ」）
  - 部室棟: 2階建て。本校舎の2階と渡り廊下でつながる
  - 校庭: 正面の左手前。楕円のトラック
  - 体育館: 右手前。平たい屋根の大きな建物
- 2年の棟と1年の棟は**渡り廊下**でつながる。3年フロアへは**階段**を上る（狭いので、一度に大勢は上がれない）
- 部室棟へも渡り廊下で行く
- 廊下は広く、大勢で押し寄せられる。階段と渡り廊下は狭く、一度に少しの人数しか通れない
- 1年の棟と購買・食堂は、廊下で直接つながる。昇降口から校庭へ、校庭から体育館・部室棟へ出られる
- 生徒会室と体育館は、守る側に有利な場所（生徒会室がいちばん守りやすい）
