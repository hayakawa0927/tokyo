# Git同期スキル

このプロジェクトの変更を、Gitリポジトリに反映する。

## 前提

- ブランチ: `main`
- リモート: `origin` = `https://github.com/hayakawa0927/tokyo.git`
- 認証: このリポジトリのローカル設定で `credential.https://github.com.username = hayakawa0927` を指定済み
- `.claude/settings.local.json` は `.gitignore` 済み（個人のローカル権限設定のため共有しない）

## 手順

### 1. リモートの最新化を確認（リモートがあるとき）
- `git fetch` してから `git status` で、ローカルがリモートより遅れていないか確認する
- 遅れている場合（別PCでの変更がある場合）は、先に `git pull` してから作業する。コンフリクトが出た場合は内容を提示し、ユーザーに解決方針を確認する

### 2. 変更内容の確認
- `git status` / `git diff` で変更ファイルを確認する
- 変更内容から日本語で簡潔なコミットメッセージ案を作る（例:「3話を新設・執筆」「docs: キャラクター設定を追記」）

### 3. ユーザーへの提示と確認
- 変更されたファイル一覧とコミットメッセージ案を提示し、ユーザーの確認を取る
- pushは共有リポジトリへの操作のため、**必ず確認を取ってから**実行する（無断でpushしない）

### 4. コミット・push
- 確認が取れたら `git add` → `git commit` →（リモートがあれば）`git push origin main` を実行する
- 終わったら `git status` で成功を確認する

## 注意
- コミットメッセージは日本語、簡潔に。何を変えたかが分かる粒度にする
- 大量の話数をまとめて1コミットにするより、作業の区切り（校正1回分、KB更新1回分など）ごとにコミットする方が履歴として追いやすい
