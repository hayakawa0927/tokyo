# 話数品質評価スキル

指定された話数の原稿を、著者が定めた**高アンカー＝135話・低アンカー＝9話**の2点で物差しを作り、5軸で採点する。

## 前提

- 高アンカー・低アンカーは、小説「現代ダンジョン奮闘記」の2話を借りる: 高アンカー＝`C:\Users\Admin\Desktop\現代ダンジョン奮闘記\135.txt`、低アンカー＝`C:\Users\Admin\Desktop\現代ダンジョン奮闘記\009.txt`（この小説の話を著者が採点したら、その話に置き換える）。著者採点は以下の通り（10点満点、0.1刻み）。

  | 軸 | 135話（高） | 9話（低） |
  |---|---|---|
  | 総合 | 8.8 | 6.0 |
  | キャラクターの個性と魅力 | 9.0 | 7.0 |
  | テンポ | 9.2 | 6.0 |
  | 文章力 | 8.3 | 5.0 |
  | 熱量・盛り上がり | 9.5 | 5.0 |

- **「総合」は4軸の平均値ではない**（135話は4軸平均9.0に対し総合8.8、9話は4軸平均5.75に対し総合6.0）。総合は読後の一体感・満足度を独立に判断した数値であり、4軸の単純平均で算出してはならない。
- 135話・9話はあくまで著者の主観的な基準点。この2点を結ぶ物差し上に他話を位置づける。**135話に似ているかだけで判断しない**。9話に近い/それ以下の弱さがないかも必ず検討する
- 採点はこの2点の間（や外側）に自由に分布してよい。5点台・6点台・7点台の話があることを前提とし、8点台後半〜9点台への収束を避ける
- 採点結果は `docs/title.md` に残す。同ファイルは「本編」「閑話」の2表に分かれている（本編のみ「章」列があり、その話が属する章を示す）。**該当話の行を探し、スコア列（総合／個性／テンポ／文章力／熱量）のセルを埋める**（新しい行や別ファイルは作らない）。
  - 再採点した場合は行を追加せず、既存セルの値を上書きする
  - 空欄（未評価）の話数はそのまま空欄にしておく

## 手順

### 1. 対象の特定
- 採点対象の話数（またはテキスト）を確認する
- 下書き段階のものは基本対象外。校正済み・確定版を対象とする（下書きの品質を見たい場合はその旨を確認する）
- `docs/title.md` 内（本編／閑話のいずれかの表）で該当話の行を探しておく。見つからない場合はタイトル未登録の可能性があるため、記入前にユーザーに確認する

### 2. 基準点と参照資料の読み込み
- 上の2つのアンカー（135話・9話）を毎回読み込み、両端の文章・展開感覚を思い出してから採点する（前回の記憶だけで済ませない）
- `docs/characters_knowledge_base.md` でキャラの口調・関係性設定を確認し、個性が出せているか照合する
- 奮闘記の `C:\Users\Admin\Desktop\現代ダンジョン奮闘記\docs\prose_style.md`・`C:\Users\Admin\Desktop\現代ダンジョン奮闘記\docs\ng_expressions.md` を確認し、文章力の評価基準に反映する
- 対象話の直前1〜2話を軽く確認し、テンポ・熱量の流れ（山場か、繋ぎの話か）を踏まえる。繋ぎの話を山場の135話と単純比較して熱量点を不当に下げない

### 3. 各軸の評価基準
135話（高）と9話（低）の両端を物差しとして、以下の観点で見る。

**キャラクターの個性と魅力（135話=9.0 / 9話=7.0）**
- セリフだけで発話者が分かるか（例: 閃の短い言い切り、爽太の軽口のツッコミ、翼の「〜っす」と食べ物の話、怜の短い質問と事実）
- 一人ひとりの反応・仕草が使い回しでなく、そのキャラ固有か
- キャラ同士の関係性（呼び方・力関係・信頼）が自然に滲んでいるか

**テンポ（135話=9.2 / 9話=6.0）**
- 一文の長さ・改行のリズム、`＊　＊　＊` によるシーン転換の切れ味
- セリフと動作描写が交互に来て、単調な説明の塊になっていないか
- 攻防の応酬が間延びせず、テンポよく積み重なっているか

**文章力（135話=8.3 / 9話=5.0）**
- 比喩・擬音・体感描写の的確さ、AIっぽい表現（`ng_expressions.md`）の有無
- 同じ表現・構文の連続使用がないか
- 視点・主語が明確で誤読を誘わないか

**熱量・盛り上がり（135話=9.5 / 9話=5.0）**
- 技の発動・命中に至るまでの溜め、失敗や消耗を挟んでの人間味
- 仲間との連携・掛け声、追い詰められてからの逆転感
- 山場として設計された話であれば、テンションの上昇カーブが135話に匹敵するか（繋ぎの話ならその点は加味する）

### 4. 採点の実施
- 採点前に、まず**軸ごとに弱点を最低1つ**（できれば具体的な本文引用つきで）探す。褒めるポイントから先に決めて逆算しない
- ある軸で本文引用つきの弱点が見つからない場合のみ、その軸は135話の基準点以上を付けてよい。見つかった場合は弱点の深刻さに応じて9話側へ寄せる
- 4軸をそれぞれ0.1刻みで採点し、根拠を対象話の具体的な描写を引用しながら示す
- 「総合」は4軸を踏まえつつも独立に、読後の満足度として判断する（平均値をそのまま出さない）
- 135話・9話それぞれと比べて優れている点・劣る点を軸ごとに明記する

### 5. 出力
- 5軸のスコア表を提示する
- 各軸ごとに、根拠（本文引用＋135話との比較コメント）を簡潔に添える
- 改善の余地がある軸があれば、具体的にどう直せば基準点に近づくか提案する（本文の書き換えは行わない。あくまで評価と提案）
- ユーザーの了承が得られたら、`docs/title.md` の該当話の行にあるスコア列（総合／個性／テンポ／文章力／熱量）を埋める

## 注意
- 校正（本文の書き換え）は行わない。品質評価に徹し、修正が必要な場合は `chapter-polish` スキルの利用を促す
- 甘い点の付け方をして135話に点数を寄せない。話ごとの実際の出来に応じて、8点台後半〜9点台以外（5〜7点台を含む）にも恐れず分布させる
- 繋ぎの話・日常回など、性質上テンポや熱量が135話（山場回）に及ばないのが自然な話については、その事情を明記した上で評価する（不当に低評価にしない）
- 直近で採点した他の話のスコアと見比べ、明確な差がある出来のはずなのに近い点数になっていないか確認する
